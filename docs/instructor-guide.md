# Instructor guide

## Recommended rhythm
1. Open with the decision prompt.
2. Teach the minimum theory needed for the lab.
3. Run the investigation as guided practice.
4. Use the notebook to generate evidence.
5. Close with competing recommendations and reversal conditions.

## Data integrity
All numerical lab datasets in this repository are synthetic and labeled as such. They are designed to teach mechanisms, not reproduce audited historical losses. Historical context pages should be paired with instructor-approved primary sources before publication in a graded assignment.

## Accessibility
Color is never the only signal. Charts require titles, axis labels, legends, and alt-text in the submitted artifact. Every module page uses the same hierarchy and explicit next-step links.

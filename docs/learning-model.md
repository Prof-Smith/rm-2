# Learning model

<div class="lead">A predictable five-stage rhythm keeps effort focused on judgment rather than navigation.</div>

<div class="steps"><div><b>1 · Frame</b><p>Start with a decision.</p></div><div><b>2 · Learn</b><p>Build the essential toolkit.</p></div><div><b>3 · Investigate</b><p>Find the failure mechanism.</p></div><div><b>4 · Model</b><p>Measure and stress.</p></div><div><b>5 · Decide</b><p>Recommend and define reversal.</p></div></div>

## Decision standard
Every submission contains five elements: **claim, evidence, uncertainty, action, and reversal condition**. Each module has one principal artifact. The notebook is an analytical workspace, not a second assignment.
